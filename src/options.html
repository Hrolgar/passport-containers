Sites

Everything Passport knows. A rule is a site's default container. A keyword is a word typed in the URL bar that opens a URL in a chosen container. A bookmark with ?passport= picks its own container when clicked.

Rules

Where a URL opens by default. Plain patterns match host and path on segment boundaries; regex sees the full URL including the query; glob uses *. The most specific match wins.

PatternTypeContainer

No rules. That is fine: keywords such as pdb live under Keywords. Add a rule only for a site that must always open in one container, whichever way you reach it.

Keywords

Type the keyword alone in the URL bar and the page opens in its container, on any machine signed in to this Firefox account. One word, no spaces.

KeywordURLContainer

Bookmarks

Bookmarks Passport manages: any with ?passport= in the URL, and everything in the Passport folder. Container here means the ?passport= hint; "none" leaves the rules to decide. Bookmarks sync through Firefox itself.

TitleURLContainerFolder

Firefox bookmark tags and keywords cannot be set by an extension, so they are not here. Folders are the bulk-organising tool that is reachable, and the URL bar searches folder names too.

Containers

All containers on this machine plus any named in a rule or keyword. Save applies name, colour and icon to Firefox directly; a rename also updates every rule, keyword and bookmark hint that used the old name. Colour and icon travel to other machines through sync.
