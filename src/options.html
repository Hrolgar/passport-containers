Passport rules

One rule per line, pattern , Container. Plain = host and path prefix. @ = regex on the full URL (use this when two accounts share a path and differ only in the query). ! = glob. # = comment. First match wins. Containers named here are created automatically on every machine signed in to this Firefox account. Use the container name Default to force the plain, uncontained profile.

Keywords

One per line, keyword , url , Container. Type the keyword alone in the URL bar, exactly like a Firefox bookmark keyword, and the page opens in that container, on any machine signed in to this account. (go keyword works too.) Unlike Firefox bookmark keywords these carry the container with them.
